# tau2 Data Preparation

Import and scaffold generators for the `tau2_airline`, `tau2_retail`, and `tau2_telecom` domains.
Documented at:

**https://docs.nvidia.com/nemo/labs-voice-agent/resources/contribute/regenerating-benchmark-data**

That page covers what each script does, when to re-run it, and how to bump the upstream pin. See also
[Fixture Data & Provenance](https://docs.nvidia.com/nemo/labs-voice-agent/evaluate-voice-agents/domain-guides/fixture-data-provenance)
for upstream sources, pinned commits, and licences.
